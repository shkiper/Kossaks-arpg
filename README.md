# Січ проти Пекла (робоча назва)

Невелика 3D action-RPG про козаків у темному фольклорному фентезі. ПК, Unreal Engine 5.8.

Чотири класи (Рубака, Характерник, Пластун, Відьма), хаб — Запорозька Січ, процедурні локації
(Дике Поле, Болота й ліси, Кургани, Фортеці, Пекло), боси з фольклору, лут і прогресія у стилі Diablo 4,
керування як у Path of Exile 2.
