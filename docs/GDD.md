# Game Design Document — «Січ проти Пекла» (робоча назва)

> Невелика 3D action-RPG про козаків у темному фольклорному фентезі.
> Документ — основне джерело правди для розробки. Код пише ШІ, тому всі
> рішення тут сформульовані максимально конкретно.

## 1. Коротко

| Параметр | Рішення |
|---|---|
| Жанр | Action-RPG (ARPG), одиночна гра |
| Платформа | ПК (Windows) |
| Рушій | Unreal Engine 5.8, C++ |
| Камера | 3D, вид зверху під кутом (ізометрична перспектива, як Diablo 4 / Path of Exile 2) |
| Керування | WASD — рух, миша — приціл, ухилення перекатом (як Path of Exile 2) |
| Графіка | Заглушки (примітиви, кольорові матеріали) на етапі прототипу |
| Сетинг | Темне фентезі на козацьких і фольклорних мотивах |
| Тон | Героїчний + гумор (у дусі Гоголя та «Енеїди» Котляревського) |
| Сюжет | Мінімальний: простий сетап і мета, без складної нарації |
| Мови | Українська (основна), англійська |
| Тривалість кампанії | ~2 години + ендгейм |
| Прогресія | У стилі Diablo 4: дерево навичок, рівні, парагон-подібна система в ендгеймі |
| Структура світу | Хаб (Запорозька Січ) + процедурно згенеровані локації |
| Збереження | Так, кілька слотів персонажів |

## 2. Сетап (сюжет)

Кінець XVII століття. Розкопуючи курган у Дикому Полі, турецький паша-чорнокнижник
зламав стародавню печать — і пекло вилізло на поверхню. Нечисть заполонила степи,
болота, ліси й фортеці. Кошовий отаман скликає найкращих: кожен, хто тримає шаблю
(або мітлу), має дійти до самого пекла й зачинити ворота.

- Мета гравця: пройти 5 локацій, перемогти боса кожної, у пеклі перемогти фінального боса.
- Подача сюжету: короткі репліки NPC у Січі та перед боями з босами. Жодних довгих кат-сцен.
- Гумор: у діалогах, назвах предметів, описах монстрів («Чорт звичайний, лінивий. Боїться ладану й тещі»).

## 3. Ігровий цикл

**Хвилина до хвилини:** рух → бій із групами ворогів → лут → використання навичок і ресурсу.

**Сесія:** Січ (торгівля, крафт, прокачка) → вихід на локацію → зачистка й пошук входу до боса →
бос → повернення до Січі з лутом.

**Довгостроково:** рівні → нові навички й вузли дерева → кращі предмети (легендарні, унікальні, сети) →
вищі рівні складності → ендгейм-розломи.

## 4. Керування та бій (стиль Path of Exile 2)

| Дія | Клавіша |
|---|---|
| Рух | WASD |
| Приціл / напрямок атаки | Курсор миші |
| Основна атака (навичка 1) | ЛКМ |
| Навичка 2 | ПКМ |
| Навички 3–6 | Q, E, R, F |
| Ухилення (перекат) | Пробіл, i-frames ~0.3 с, перезарядка 1 с |
| Зілля здоров'я | 1 |
| Взаємодія / підняти предмет | Клік по предмету або Alt-підсвітка |
| Інвентар / Дерево навичок / Мапа | I / T / Tab |

Принципи бою:
- Атаки спрямовані в бік курсора, персонаж не зупиняється під час руху (крім важких атак).
- Вороги мають читабельні телеграфи атак (червона зона на землі) — від них можна ухилитися.
- Хіт-стоп, відкидання й «stagger» для відчуття ваги ударів.
- Зілля: обмежена кількість зарядів (5), поповнюються від вбивств і в Січі.

## 5. Характеристики персонажа

**Основні атрибути** (як у Diablo 4):

| Атрибут | Дає |
|---|---|
| Сила (Strength) | Броня; шкода навичок Рубаки |
| Спритність (Dexterity) | Шанс криту; шкода навичок Пластуна |
| Розум (Intelligence) | Опір стихіям; шкода навичок Характерника та Відьми |
| Сила волі (Willpower) | Лікування, регенерація ресурсу |

**Вторинні:** здоров'я, броня, опори (вогонь, холод, блискавка, отрута, темрява), шанс і шкода криту,
швидкість атаки, швидкість руху, скорочення перезарядки, регенерація ресурсу.

**Типи шкоди:** фізична, вогонь, холод, блискавка, отрута, темрява (нечиста сила), **освячена**
(бонусна шкода по демонах і нежиті — тематична фішка).

**Стани:** кровотеча, горіння, заморожування, оглушення, отруєння, **переляк** (ворог тікає), **прокляття**.

## 6. Класи

Кожен клас має унікальний ресурс, власне дерево навичок і ~15–20 активних навичок (у вертикальному зрізі — 6–8).
Гравець одночасно тримає до 6 активних навичок на панелі.

### 6.1. Рубака (запорожець, ближній бій)
- **Ресурс:** Лють — накопичується від ударів, витрачається на сильні навички.
- **Зброя:** шабля + шабля, шабля + щит, дворучна (келеп, бердиш).
- **Навички (приклади):**
  - *Рубка* (базова) — швидкий удар шаблею, генерує Лють.
  - *Вихор шабель* — обертання з шкодою навколо.
  - *Бойовий гопак* — стрибок у ціль з ударною хвилею при приземленні.
  - *Козацький клич* — бафф шкоди собі, переляк ворогам.
  - *Непохитність* — тимчасове скорочення шкоди та імунітет до контролю.
  - *Удар руків'ям* — оглушення.
  - Ультимейт: *Шалений запорожець* — 10 с підвищеної швидкості атаки та вампіризму.

### 6.2. Характерник (маг-воїн, перевертень)
- **Ресурс:** Характер — регенерується з часом.
- **Зброя:** шабля + пістоль, або посох-ціпок, талісмани.
- **Фішка:** перемикання між людською подобою (заклинання) та **вовчою подобою** (швидкі атаки в ближньому бою).
- **Навички (приклади):**
  - *Кігті вовка* (базова, вовча подоба) / *Іскра* (базова, людська подоба).
  - *Замовляння від кулі* — щит, що відбиває снаряди.
  - *Степовий смерч* — вихор, що рухається вперед.
  - *Блискавка з ясного неба*.
  - *Морок* — стати невидимим на короткий час.
  - Ультимейт: *Вовкулака* — велика форма перевертня на 12 с.

### 6.3. Пластун (розвідник, дальній бій)
- **Ресурс:** Зосередженість — регенерується швидко, витрачається малими порціями.
- **Зброя:** рушниця (сильно, повільно), пара пістолів (швидко), лук.
- **Навички (приклади):**
  - *Пістольний постріл* (базова).
  - *Прицільний постріл* — пробиває ворогів наскрізь.
  - *Капкан* — пастка з кровотечею.
  - *Бочка пороху* — кидок, вибух по площі.
  - *Очерет* — невидимість і відрив.
  - Ультимейт: *Засідка* — з'являються примарні пластуни й роблять залп.

### 6.4. Відьма (знахарка, прокляття й виклики)
- **Ресурс:** Відьомська сила — регенерується, бонус від вбивств проклятих ворогів.
- **Зброя:** ціпок, мітла (дворучна), ляльки-мотанки й амулети (другорядна рука).
- **Навички (приклади):**
  - *Пучок полину* (базова) — снаряд з отрутою.
  - *Прокляття* — ворог отримує більше шкоди, шкода з часом.
  - *Зграя ворон* — виклик птахів, що атакують.
  - *Казанок* — кинутий казан з варивом, калюжа отрути або холоду.
  - *Політ на мітлі* — переміщення крізь ворогів.
  - Ультимейт: *Шабаш* — поле, в якому вороги сповільнені, а відьма лікується.

### 6.5. Дерево навичок (стиль Diablo 4)
- Дерево розділене на яруси: **Базові → Основні → Захисні → Спеціальні → Могутні → Ультимейт → Ключові пасивки**.
- Кожен ярус відкривається, коли вкладено N очок у попередні (наприклад, 2 / 6 / 11 / 16 / 23 / 33).
- Активна навичка має до 5 рангів + 2 варіанти покращення («Посилене», потім вибір з двох модифікацій).
- Пасивні вузли між навичками.
- 1 очко за рівень (до 50), + очки від особливих завдань.
- Скидання вузлів за дукати в Січі (дешево).

### 6.6. Рівні
- Максимальний рівень кампанії: **50** (кампанія ~2 години закінчується приблизно на 30–35 рівні).
- Після 50 — **Слава** (аналог парагону): дошки з пасивками, 1 очко за рівень Слави.
- Досвід до наступного рівня: `XP(n) = round(100 * n^1.6)` (для балансу, змінюється в даних).

## 7. Хаб — Запорозька Січ

Безпечна локація, звідки гравець вирушає на інші. NPC:

| NPC | Функція |
|---|---|
| Кошовий отаман | Видає головні завдання, коротко знайомить із сюжетом |
| Коваль | Покращення предметів, розбирання на матеріали, виготовлення |
| Корчмар | Торговець: зілля, базові предмети, покупка й продаж |
| Знахарка | Зачарування: перекидання одного афікса предмета (як Окультист у D4) |
| Кобзар | Кодекс легендарних аспектів: зберігає аспекти й накладає на предмети |
| Писар | Скриня для предметів (спільна для персонажів) |
| Вербувальник | Вибір рівня складності і вхід в ендгейм-розломи |

Січ — невелика ручна локація (не процедурна). Портали/брама на локації.

## 8. Локації

Процедурна генерація всіх бойових локацій (див. `TECH.md`, розділ «Процедурна генерація»).
Кожна локація: 1–2 відкриті зони + 1 підземелля/фінальна арена з босом. ~20–25 хв на першому проходженні.

| # | Локація | Настрій | Звичайні вороги | Бос |
|---|---|---|---|---|
| 1 | **Дике Поле** | Степ, ковила, кургани вдалині, спалені хутори | Упирі, вовкулаки, мертві ординці (лучники), чорти-підпалювачі | **Змій Горинич** (3 голови — вогонь, холод, отрута) |
| 2 | **Болота й ліси** | Туман, трясовина, старі дуби | Потопельники, мавки, лісовики, болотяні вогники, відьмині коти | **Болотяник** (водяник, затягує гравця у трясовину) |
| 3 | **Кургани** | Підземні скіфські поховання, золото, кістки | Скіфські мерці, кам'яні баби (статуї, що оживають), кажани, упирі-вельможі | **Вій** («Підніміть мені повіки!» — фаза, коли погляд Вія вбиває, треба ховатись за колонами) |
| 4 | **Фортеці** | Османська фортеця, захоплена нечистю: мури, гармати, мінарети | Мертві яничари, гармаші-скелети, джини, некроманти | **Паша-чорнокнижник** (викликає нежить, стріляє з гармат фортеці) |
| 5 | **Пекло** | Казани, сірка, вогонь, пародія на Січ (з гумором, як у «Енеїді») | Чорти всіх мастей, біси-писарі, пекельні пси, грішники | **Люципер** (фінальний бос, 3 фази) |

**Типи ворогів** (для балансу та ШІ): звичайні, чемпіони (сильніші, 1–2 модифікатори), еліти (з прислужниками,
2–4 модифікатори як «Вогняний», «Швидкий», «Щитоносець», «Прокльонник»), боси.

## 9. Боси

Кожен бос — окрема арена, 2–3 фази, чіткі телеграфи атак, власна механіка:

- **Змій Горинич:** кожна голова має свою атаку (подих вогню / холоду / отрути). Відрубування голови (знищення її HP-смуги) прибирає атаку, але решта лютішають.
- **Болотяник:** зони трясовини сповільнюють гравця; бос пірнає й з'являється під гравцем; викликає потопельників.
- **Вій:** періодично «піднімає повіки» — промінь погляду по лінії; треба сховатися за колоною. Між фазами — хвилі нечисті.
- **Паша-чорнокнижник:** на арені гармати, які можна обернути проти нього; у 2-й фазі стає демоном.
- **Люципер:** фаза 1 — ближній бій; фаза 2 — арена горить, треба стояти на безпечних плитах; фаза 3 — викликає попередніх босів у вигляді тіней (по одній атаці кожного).

Бос гарантовано дропає рідкісний предмет і має шанс на легендарний / унікальний.

## 10. Предмети та лут (стиль Diablo 4)

### 10.1. Слоти спорядження
Шапка, Жупан (тіло), Рукавиці, Шаровари, Чоботи, Пояс, Ладанка (амулет), 2 персні,
Основна зброя, Другорядна зброя/щит/талісман, **Люлька** (унікальний слот — див. нижче).

**Люлька:** особливий слот. Має активну властивість: гравець «закурює» (клавіша 2) і отримує бафф на 15 с
(наприклад, «+20% швидкості атаки» або «+30% опору вогню»), перезарядка 60 с. Люльки — окремий тип луту.

### 10.2. Рідкісність

| Рідкісність | Колір | Афікси |
|---|---|---|
| Звичайний | Білий | 0 |
| Магічний | Синій | 1–2 |
| Рідкісний | Жовтий | 3–4 |
| Легендарний | Помаранчевий | 3–4 + **легендарний аспект** (змінює механіку навички) |
| Унікальний | Золотий | Фіксовані афікси + унікальна властивість + назва й опис |
| Сетовий | Зелений | Фіксовані афікси + бонуси за 2/4/6 предметів сету |

- **Сила предмета (Item Power)** залежить від рівня монстра, що його випустив, і рівня складності.
- Афікси мають діапазони значень; якість ролу видно в підказці.
- Легендарні аспекти можна «витягти» з предмета й зберегти в Кодексі (Кобзар).

### 10.3. Приклади унікальних предметів
- **Шабля Івана Сірка** — вороги, вбиті шаблею, мають шанс налякати сусідів. «Він писав листи султанові. Шабля пише коротше».
- **Люлька Сагайдачного** — закурювання викликає примарну чайку, що обстрілює ворогів.
- **Пірнач Богдана** — +1 до рівня всіх навичок; кличі мають подвійний радіус.
- **Мітла Солохи** (Відьма) — політ на мітлі залишає вогняний слід.
- **Шапка Характерника** — вовча подоба триває вдвічі довше.
- **Рушниця Пластуна-невидимки** — перший постріл після невидимості завжди критичний.

### 10.4. Сети (приклади)
- **Обладунок Хортиці** (Рубака), **Регалії Характерників**, **Спорядження Сірих Вовків** (Пластун), **Шабаш Лисої Гори** (Відьма).

### 10.5. Економіка та крафт
- **Валюта:** дукати.
- **Матеріали:** залізо (з розбирання зброї), шкіра (з обладунків), трави (збір на локаціях), бурштин (рідкісні предмети), пекельна сірка (легендарні / пекло).
- **Коваль:** покращення предмета (до 5 разів, + до основних характеристик), розбирання, створення зілль вищого рівня.
- **Знахарка:** перекидання одного афікса (після вибору афікс заблоковано для цього предмета), вартість росте.
- **Кобзар:** накладання легендарного аспекту на рідкісний предмет (робить його легендарним).

## 11. Складність

| Рівень | Доступ | Вороги | Нагорода |
|---|---|---|---|
| Джура | З початку | −30% HP/шкоди | Базова |
| Козак | З початку | Базові значення | Базова |
| Отаман | Після проходження кампанії | +100% HP, +50% шкоди | +50% досвіду, більше легендарних |
| Кошовий | Після розлому 20-го рівня | +250% HP, +100% шкоди | Сетові предмети, кращі аспекти |

**Хардкор** (прапорець при створенні персонажа): смерть — персонаж назавжди видаляється.

## 12. Ендгейм

- **Пекельні розломи:** процедурні підземелля з рівнями 1–100 (як Nightmare Dungeons / Pit у D4). Ключ — **Печатка**, яка випадає з монстрів. Печатка має модифікатори («Вороги швидші», «Земля горить») — вищий ризик, більша нагорода.
- Таймер проходження, фінальний бос розлому. Успіх відкриває наступний рівень.
- **Слава** (парагон) — див. 6.6.
- Щотижневий «Похід на Люципера» на вищій складності (опційно, пізніше).

## 13. Збереження

- Кілька слотів персонажів (до 8).
- Автозбереження: при вході в Січ, при переході між зонами, після вбивства боса, при виході.
- Зберігається: персонаж (клас, рівень, атрибути, дерево навичок), інвентар і спорядження, скриня (спільна), прогрес кампанії, Кодекс, відкриті рівні складності й розломів.
- Процедурні локації не зберігаються — генеруються знову при вході (зі збереженим прогресом завдань).

## 14. Інтерфейс (HUD)

- Кулі/смуги здоров'я й ресурсу, панель із 6 навичками й перезарядками, заряди зілля, люлька.
- Смуга досвіду.
- Міні-мапа у куті, повна мапа по Tab.
- Смуга HP над ворогами (еліти й боси — з назвою та модифікаторами).
- Цифри шкоди (вимикаються в налаштуваннях).
- Підписи предметів на землі з кольором рідкісності; фільтр луту (простий).
- Підказки предметів із порівнянням з одягненим.

## 15. Аудіо

На етапі прототипу — заглушки/безкоштовні звуки. Згодом — етнічна музика (кобза, бандура, сопілка, трембіта,
дарк-фолк), бойові вигуки українською.

## 16. Локалізація

- Усі тексти — лише через String Tables / FText, жодного захардкодженого тексту.
- Мова за замовчуванням — українська, друга — англійська; перемикання в меню.
