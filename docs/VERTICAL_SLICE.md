# Вертикальний зріз (Vertical Slice)

Мета: маленька, але повна версія гри, яка доводить, що основний цикл цікавий:
**Січ → Дике Поле → бій → лут → бос → Січ**. Графіка — заглушки.

## Обсяг

| Елемент | У зрізі |
|---|---|
| Класи | **1 — Рубака** (найпростіший для реалізації ближній бій; архітектура одразу під 4 класи) |
| Навички | 7 активних (див. нижче) + ~10 пасивних вузлів дерева |
| Рівні | 1–12 |
| Хаб | Мінімальна Січ: Кошовий, Корчмар (купівля/продаж), Коваль (розбирання + покращення), скриня |
| Локації | **Дике Поле**: 1 процедурна відкрита зона + 1 процедурне підземелля (курган) + арена боса |
| Вороги | 4 типи + варіанти «чемпіон» і «еліта» з 3 модифікаторами |
| Бос | **Змій Горинич** |
| Лут | Білі, сині, жовті, легендарні (3 аспекти), 1 унікальний (Шабля Івана Сірка) |
| Складність | Джура / Козак |
| Збереження | 3 слоти, автозбереження |
| Локалізація | uk + en з першого дня |
| Тривалість | ~20–30 хв гри |

Поза зрізом: інші класи, решта локацій, сети, люльки, Знахарка й Кобзар, ендгейм, хардкор.

## Навички Рубаки у зрізі

| Навичка | Ярус | Опис | Ресурс |
|---|---|---|---|
| Рубка | Базова | 3-ударне комбо шаблею по дузі перед персонажем | +8 Люті за удар |
| Вихор шабель | Основна | Обертання 1.5 с, шкода навколо, можна рухатися повільно | −25 Люті |
| Бойовий гопак | Основна | Стрибок до точки курсора (до 8 м), ударна хвиля радіусом 3 м, відкидання | −30 Люті |
| Непохитність | Захисна | 4 с −40% отриманої шкоди, імунітет до контролю | КД 18 с |
| Козацький клич | Захисна | Переляк ворогів у радіусі 6 м на 3 с, +15% шкоди собі на 8 с | КД 20 с |
| Удар руків'ям | Спеціальна | Короткий удар, оглушення 2 с | КД 8 с |
| Шалений запорожець | Ультимейт | 10 с: +30% швидкості атаки, 10% вампіризму | КД 60 с |

## Вороги Дикого Поля

| Ворог | Роль | Поведінка |
|---|---|---|
| Упир | Базовий ближній | Іде на гравця, повільний удар з телеграфом; групи по 4–8 |
| Вовкулака | Швидкий ближній | Кружляє довкола, стрибає з телеграфом-лінією, відступає |
| Мертвий ординець | Дальній (лучник) | Тримає дистанцію 10–14 м, стріляє; тікає від гравця |
| Чорт-підпалювач | Кастер | Кидає вогняні калюжі (зона горіння), викликає 2 упирів раз на 15 с |

Модифікатори еліт у зрізі: **Вогняний** (залишає вогонь при смерті), **Швидкий** (+40% швидкості),
**Щитоносець** (щит для союзників поруч).

## Бос: Змій Горинич

- Арена: кругла, ~30 м, по краях каміння для укриття.
- 3 голови з окремими смугами HP + спільна смуга тіла.
  - Ліва — подих вогню (конус, залишає горіння на землі).
  - Центральна — укус (ближній, телеграф-коло).
  - Права — отруйні плювки (3 снаряди-калюжі).
- Коли голову «відрубано» (HP = 0), її атака зникає, решта атакують на 20% швидше.
- Коли всі голови відрубано — фаза 2: тіло тупцює (ударні хвилі) до смерті.
- Нагорода: 1 гарантований рідкісний, 30% шанс легендарного, 5% — Шабля Сірка; велика порція досвіду.

## Критерії готовності (acceptance)

1. Нова гра → вибір слоту → створення Рубаки → з'являєшся в Січі.
2. У Січі можна купити/продати предмет у Корчмаря, розібрати/покращити в Коваля, покласти предмет у скриню.
3. Вихід через браму генерує Дике Поле; кожен вхід — інша карта (зміна seed).
4. Керування WASD + миша + перекат працює плавно, камера слідкує за персонажем.
5. Усі 7 навичок працюють, витрачають/генерують ресурс, мають перезарядки та відображаються на HUD.
6. Вороги 4 типів з'являються групами, мають ШІ з розділу вище, вмирають, дають досвід і лут.
7. Лут падає з правильною рідкісністю й випадковими афіксами; можна одягнути, характеристики змінюються.
8. Рівень підвищується, очки навичок вкладаються в дерево.
9. У зоні знаходиться вхід до кургану, з кургану — на арену боса; Горинич працює за описом.
10. Після смерті гравця — відродження в Січі або на чекпоінті (без втрати предметів).
11. Прогрес зберігається і відновлюється після перезапуску гри.
12. Перемикання uk/en у меню змінює всі тексти.
13. Стабільні 60 FPS на середньому ПК з заглушками.

## Етапи розробки

| # | Етап | Результат |
|---|---|---|
| M0 | Каркас проєкту | UE-проєкт, модулі C++, структура папок, Enhanced Input, GAS підключено |
| M1 | Персонаж і камера | Рух WASD, поворот до курсора, перекат, камера |

| M3 | Вороги | Базовий клас ворога, ШІ (StateTree / Behavior Tree), 4 типи, спавн груп |

| M6 | Прогресія | Досвід, рівні, дерево навичок, панель навичок |
| M7 | Січ і збереження | Хаб, NPC-функції, скриня, SaveGame, меню, слоти |
| M8 | Бос | Змій Горинич, арена, фази |
| M9 | Полірування | Локалізація, HUD, баланс, фідбек ударів, звуки-заглушки |
